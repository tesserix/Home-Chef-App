## The two open money problems

**#947 — chefs are owed ₹710.53 and it reaches nobody.** `vendor_kept_paise` is
computed, persisted, shown to the customer, and never paid. **The ambiguity is
resolved** — epic #475 says plainly *"the withheld % becomes the vendor's
payout"*, so it is the chef's money and reading 1 is correct. No owner decision
is needed; the evidence is in a comment on the issue.

The fix is not small and was deliberately not attempted in a low-context session.
The hold is only a status column; the payout amount is derived at settle time
from the order. Cancelled orders are excluded at three guards that exist to stop
a refunded order paying a chef out of returned money:

- `services/payout_release.go:167` and `:391`
- `services/payout_hold.go:165`

Shape suggested on the issue: record the entitlement at cancellation resolution,
let the payout path settle *that recorded amount* for cancelled orders only,
re-prove conservation end-to-end, then backfill the 9 rows. **A mistake here pays
a chef from a refunded capture — do not rush it.**

**#948 — one deleted customer strands ₹443.45.** User `91768f92-7bdb-4d3e-a3ce-4416f33c668f`
has no `users`/`wallets`/`wallet_txns` row but owns 3 orders, a ₹145.87 ledger

## Traps worth carrying forward

- **Do NOT add `@react-native/jest-preset` to any app.** `6435cc39` reverted it:
  it re-keys react-native's peer resolution, relocates it under
  `node-linker=hoisted`, and both apps fail to compile at `ExpoLinking.js`. I
  nearly shipped this in #950 and stripped it before merge. #959 solved it with a
  standalone `jest.config.js` — no dependency, no lockfile churn. Vendor/admin/
  delivery still need the same treatment.
- **Test fixtures do not model the real schema.** Five hand-rolled sqlite
  `orders` tables were missing `cancelled_at`, `refund_id`, `wallet_applied`,
  `status`, `payment_status`, `refund_amount`. Tests passed only because the code
  never wrote those columns — the fixtures were confirming the bugs. Expect this
  again on any new column.
- **Check for leftovers before measuring.** `@react-native/jest-preset` was still
  in local `node_modules` after I reverted package.json, which would have made
  every local jest result meaningless. Removed it before believing anything.
- **The DB is UTC; you are UTC+10.** I briefly mis-read a 30-minute-old order as
  14 hours old and wrongly concluded the stale-order cron was broken. It is fine
  — it cancels abandoned checkouts at exactly the 30-minute mark.
- `git log -1 <commit> -- <path>` shows the last commit touching that path *up
  to* that commit, not that commit. Use `git show --stat --name-only`.
- Prod deploy tags can advance ahead of the image build; check the API CI build
  completed before concluding a backend change is live.
